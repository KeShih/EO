# EO Materials

This repository collects the paper, poster, and supporting AI interaction records related to the EO project.

## Main files

- [eo-lp-paper.pdf](eo-lp-paper.pdf): The paper on an LP algorithm for counting Eulerian orientations through the lens of quasi-polymorphism.
- [eo-lp-poster.pdf](eo-lp-poster.pdf): The poster for the EO project.

## AI-related records

- [ai-interaction-records.pdf](ai-artifacts/ai-interaction-records.pdf): A record of interactions with AI systems during the project.
- [ai-generated-f56-hardness-false-proof.pdf](ai-artifacts/ai-generated-f56-hardness-false-proof.pdf): An AI-generated proof attempt claiming that $f_{56}$ is $#\mathrm{P}$-hard. This proof is included as an incorrect proof attempt, not as a valid result.
- [ai-thought-process-cubic-forms.pdf](ai-artifacts/ai-thought-process-cubic-forms.pdf): A record of the AI's thought process that led to considering cubic forms. Interestingly, the transcript does not appear to show the AI explicitly exploring cubic forms before the idea surfaces, making the emergence of this direction noteworthy. After the cubic-forms idea surfaced, a follow-up query led the AI to judge its own idea as incorrect, which is another notable part of the record.

These AI-related files are included for provenance and context around the discovery process. The AI interactions used GPT-5.4 Thinking with xhigh reasoning effort and Pro models.
